# sorry

A small, static, animated letter page. The page content lives in `message.js`; the design and interactions are in `index.html`, `style.css`, and `script.js`.

## Deploy on Vercel

1. Import `manishlivnium-coder/sorry` from GitHub in Vercel.
2. Choose **Other** as the framework preset.
3. Leave the build command empty and set the output directory to `.`.
4. Deploy.

There is no build step; Vercel serves `index.html` and its local assets directly.
